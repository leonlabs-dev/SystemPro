# Asset Provenance

## Project assets

The logo and product-specific WebP illustrations under `src/assets/images` are application artwork. Before a public release, the repository owner must confirm that these assets may be redistributed under the future repository license. The source contains no embedded font files.

The UI uses operating-system font stacks, so no web-font binary is redistributed.

## Map data

China map geometry is loaded from the `china-geojson` npm package. Its package manifest declares MIT licensing; attribution details are recorded in `THIRD_PARTY_NOTICES.md`.

## Icons and trademarks

Element Plus icons and Simple Icons are used through npm packages. Simple Icons data is CC0-1.0, but individual brand names and marks may still be protected by trademark rules. A package license does not grant trademark endorsement.

## Release rule

Do not add an image, font, map, video, or copied design asset unless its origin and redistribution terms can be recorded here or in `THIRD_PARTY_NOTICES.md`.
