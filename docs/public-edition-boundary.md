# SystemPro 公开源码版能力边界

SystemPro 公开源码版保留完整的产品导航、路由、主题、国际化和权限入口，便于评估产品结构与公开能力。部分商业业务域仅在正式版交付，公开仓库中的对应页面使用统一占位组件，不包含其页面实现、写操作接口或业务模型。

## 公开实现

- 运营驾驶舱、资产设备、能源计量、能源流向与运行监控。
- 历史告警统计。
- 账号生命周期、角色权限、菜单权限和第三方登录绑定。
- 组织架构、部门岗位和空间层级。
- 基础参数和多语言管理。

## 正式版能力占位

- 租户与客户档案管理。
- 告警规则、告警转工单和复杂工单流程。
- 银企直连、收款核销、调账退款、开票和账单生命周期。
- 数据字典维护和完整审计后台。

占位页面保留稳定 URL、菜单名称和权限边界，因此公开体验不会出现空白页面或 404。公开体验服务返回的菜单并不代表相关商业实现源码包含在本仓库中。

## 维护约束

- 闭源页面只允许引用 `ModulePlaceholder.vue`，不得复制私有仓库中的业务实现。
- 公开模块确需复用的只读查询和运行时字典接口可以保留；闭源页面专用的写接口、模型和组件不得进入公开仓库。
- 私有管理端与公开仓库独立维护，功能同步必须按清单选择性移植。
